# PrivateAuth Shield

A modern, highly polished, privacy-first authentication command center configured with local zero-knowledge design patterns, WebAuthn criteria simulation, and cell-free multi-factor credentials management. Built for software engineering portfolio verification.

---

## 🎨 Visual Identity & Aesthetic Alignment
- **Space-Grade Dark Aesthetics**: A premium slate-off-black cybersecurity theme engineered with precise color contrasts, spacious layout tracking, and a dynamic Cyan/Violet dual color profile.
- **Intelligent Sidebar Drawer**: A sticky, scroll-contained responsive design supporting flawless mobile layout adjustments and clean hover animations.
- **Micro-Interactive Score Gauges**: Interactive gauges on the security dashboard that collapse into responsive granular checkmarks for dynamic point calculations.

---

## 🔒 Security Simulation Protocols
- **Biometric WebAuthn Passkeys**: Simulates low-level hardware-level private keys. Includes error throttling during suspicious inputs.
- **MFA TOTP Core Engine**: Time-based seed generators running zero SMS phone-routing frameworks, protected completely against SIM-swap attacks.
- **Argon2id Memory-Hard Recovery**: Uses single-use offline cryptographic restore matrices to bypass failed devices securely.
- **Active Session Footprint**: Clear listing of cached cookies, browser agents, and timestamps with dynamic instantaneous session revocation.

---

## 🛡️ Privacy Guard Architecture
- **Raw IP Obfuscation**: IP digits are dynamically masked/truncated at ingestion inside client memory to prevent deep geographic telemetry profiling.
- **Sovereign Wipe Action**: Implements an irreversible account self-destruct command that clears local states, cookies, recovery tokens, and browser memory instantaneously.
- **Zero Raw Metadata Tracking**: No full system tracking or unverified background coordinates are processed or saved.

---

## ⚙️ Tech Stack & Modularity
- **Framework**: `React v19` + `Vite` for lightweight, HMR-free local rendering.
- **Styling**: `Tailwind CSS` utility framework.
- **State Engine**: Centralized state orchestration persistence using unified browser `localStorage` hooks.

---

## 📣 Portfolio Notice
> **IMPORTANT PLATFORM NOTE**: This is a frontend prototype and security simulation designed for portfolio presentation. For live enterprise production environments, real WebAuthn browser registration interfaces, server-side TOTP validation seeds, strict TLS handshakes, backend databases, and secure token rotation cookies must be implemented.
